What these drawings include

The complete atlas’s 359 selected ramp and approach paths across 84 interchange and access groups. These are selections, not an exhaustive inventory of every physical Parkway ramp. All 12,877 original XY vertices are retained, including four explicit excerpts of longer highway records.

The coordinates are copied from GSP_Parkway_County_Refined.html and checked against the uploaded NJ_Roads_shp.zip. The roadway snapshot is August 21, 2025; it is not a current-condition survey.

Source: NJDOT Roadway Network. County outlines are the prior atlas’s generalized NJOGIS-derived display copy. They are contextual, not survey boundaries.

How the overlay works

Default: subtract each path’s first recorded vertex and place those vertices at one shared origin. A single global scale preserves relative lengths, shape and compass orientation. No paths are rotated to point in the same direction.

Other anchors use the last vertex, the documented Parkway-side end (start for exits, end for entrances), or the existing vertex nearest half the path length. A Parkway-side end can be on a collector or another ramp—not the mainline itself. “Fit each path separately” changes relative size and is explicitly labeled. In that optional mode, each path’s farthest original vertex is brought to the same displayed radius. The circular outer envelope is a scaling effect, not a roadway feature.

How the animation works

Paths begin at their actual projected map locations at one common scale. Each complete polyline moves and uniformly scales into its own tile, then returns to its original location. The bends themselves do not morph. Animation describes a display transition, not traffic.

Native SVG paths use only straight-line segments through the original recorded points. Rounded stroke joins do not add new coordinate geometry. Line width is illustrative. Reduced-motion preferences disable autoplay.
