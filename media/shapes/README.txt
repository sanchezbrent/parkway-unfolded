Garden State Parkway — isolated source shapes

359 transparent PNGs, one for every selected path in the completed 172–0 study.
Files are grouped by interchange. Access 12 is an entrance-only access group.
Each filename includes its number, NB/SB direction, exit/entrance type,
connecting road, and unique study selection ID. Shape_Index.csv provides the
full descriptions, source identifiers, original source notes, and export details.

The shapes contain only the original selected centerlines. There are no labels,
backgrounds, context roads, shadows, endpoint markers, or locator graphics.
Exits use the established amber (#a15b00); entrances use teal (#226d60).

PNG longest edge: 2400 pixels, including 64-pixel transparent margins.
Stroke: 18 pixels with round caps and joins; edges are antialiased.
Images are tightly fitted and therefore have different width/height dimensions.

Grid north remains up. Every original point is used in its original sequence.
Each path is translated and uniformly scaled, with no rotation, independent
axis stretching, smoothing, or invented curves. Each file is fitted separately:
equal displayed sizes do not imply equal real-world lengths. Use the length
and scale columns in the index when making quantitative size comparisons.

Source: NJDOT August 21, 2025 centerline snapshot, NAD83 / New Jersey
(EPSG:3424), US survey feet. Exported from the existing verified study kit.
This is the study's 359 selected paths across 84 interchange/access groups,
not a complete inventory of all possible movements. Some paths are feeders,
shared approaches, or documented excerpts of longer source records.
Centerline strokes do not represent pavement width. Sparse source geometry is
preserved as supplied. These drawings do not establish current road conditions.
